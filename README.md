I have a relatively busy week this week, and the next update to Game Tutorial will probably be quite large, so I decided to take a break from it and do something more laid back this week. This project is a searchable archive of transcripts from the audio drama/podcast "The Magnus Archives". TMA is very complex, and has a lot of smaller plot lines with minor characters that are hard to keep track of over its 200 episode run time. This is the solution.
